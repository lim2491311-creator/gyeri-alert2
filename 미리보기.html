NOTIFICATIONS

새 공고는 웹 알림
또는 이메일로.

웹 알림은 이 웹사이트를 열었을 때 새 공고를 알려드립니다. 이메일은 GitHub에서 자동 확인하므로 사이트를 닫아도 받을 수 있습니다.

웹 알림 설정 확인 중
이메일 연결 상태 확인 중
01
GitHub Pages 연결

압축파일을 GitHub 저장소에 올려 웹사이트를 엽니다.

02
이메일 연결 (선택)

Gmail 앱 비밀번호 및 수신주소를 GitHub Secrets에만 저장합니다. 사이트에는 이메일 주소를 표시하지 않습니다.

03
자동 감시 활성화

약 1시간마다 우정사업본부와 국가공무원 채용시스템을 점검합니다. 새 공고가 있을 때만 메일이 발송됩니다.

웹사이트 알림은 사이트를 열어둔 상태 또는 다시 방문할 때만 표시됩니다. 브라우저를 닫은 상태에서도 받으시려면 이메일 알림을 연결하세요.
